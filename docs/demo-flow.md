# Demo Flow (SIH demonstration — target state)

Demo innovation: **AshwaBrahm Low-Temperature Herbal Formulation**
(scaffolded under `data/demo/ashwabrahm/`; illustrative content only).

1. **Create innovation** — fill the innovation form (`/dashboard`).
2. **Analyse** — run IP / TK / ABS / regulatory analysis (`/analysis`).
3. **View evidence** — browse jurisdiction-filtered evidence and the
   claim-to-evidence map (`/evidence`).
4. **Open Scenario Lab** — pick a base innovation version (`/scenario-lab`).
5. **Modify innovation** — apply changes (ingredients, process, claims…).
6. **Compare** — side-by-side scenario diff with impact deltas.
7. **Red-team** — run attacks, review weaknesses (`/red-team`).
8. **Research gaps** — coverage map of unsupported claims.
9. **Final report** — generate the evidence-grounded report (`/reports`).

All demo evidence is labelled `Prototype / illustrative evidence` until
verified integrations land in Phase 2.
