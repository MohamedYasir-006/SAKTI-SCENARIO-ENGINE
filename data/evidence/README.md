# Evidence placeholders (Phase 1)

Real evidence corpora arrive in Phase 2. Directories:

- `patents/` — patent register extracts (to be integrated; never invent numbers).
- `traditional-knowledge/` — TK references (to be integrated).
- `abs/` — ABS / biodiversity register extracts (to be integrated).
- `regulatory/` — regulatory sources (to be integrated).

All unverified content must carry the label `Prototype / illustrative evidence`.
